# RowdyQL

סביבת לימוד אינטראקטיבית לקורס "תכנון בסיסי נתונים" (אוניברסיטת אריאל, הנדסת תעשייה וניהול).
מבוא לעולם ה-SQL, אלגברה רלציונית עם ממחישים, תרגילים ובחינה עצמית. עברית ואנגלית.

- `src/page.html` — מקור הדף (גוף בלבד, בלי html/head/body).
- `build.py` — עוטף את המקור ל-`index.html` העצמאי שמוגש ב-GitHub Pages.
- `index.html` — הקובץ שמוגש. לא לערוך ידנית; לערוך את המקור ולהריץ `python build.py`.

## מהדורות ושיעורים

- **שתי מהדורות באותו קוד:** `campus` (הקורס באוניברסיטה: מפגשים, תאריכים, מה נלמד בהרצאה, קוד מרצה) ו-`public` (הקורס העצמאי). `SITE_EDITION` קובע מה כולם רואים; `?preview=public` מציג את המהדורה העצמאית בדפדפן הנוכחי בלבד.
- **מחרוזות:** הטקסטים ב-`I18N` ניטרליים. מה שקשור לאוניברסיטה יושב ב-`I18N_CAMPUS` וב-`CAMPUS` (תאריכים, איזה שיעורים בכל מפגש), ודורס רק במהדורת הקמפוס. אלמנט שקיים רק בקמפוס מקבל `data-only="campus"`.
- **שיעורים:** `COURSE` מחלק כל פרק (יחידה) לשיעורים של 15 עד 20 דקות: `{ id, secs, min }`, והכותרת במפתח `ls_<id>`. שיעור של מהדורה אחת בלבד מקבל `only: 'public'`. תוכן חדש נבנה ישר כשיעורים.
- **בהשקה:** `SITE_EDITION = 'public'` ואיפוס כל החשבונות.
